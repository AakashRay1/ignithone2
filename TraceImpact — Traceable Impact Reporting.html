Import & Combine Program Records

Bring in spreadsheets, form exports, or paper-log CSVs. Nothing is altered — each file is stored as-is, and you map its columns onto shared fields.

Why mapping?

Each source names things differently — "Name" vs "Full Name", "Session Date" vs "Date". Map each source's own columns to five shared fields (Beneficiary, Program, Date, Metric Value, Unit) so records from every file can be combined and compared. Unmapped optional fields are simply left blank.

Integrity & Reconciliation

Combined records are checked for likely duplicates (same beneficiary + program + date, however the name was typed) and for missing required fields. Nothing is deleted — you choose what to exclude from calculations, and that choice is logged.
